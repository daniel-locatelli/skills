# Eval results: baseline (no gate)

- **Arm:** baseline. No `citing-sources` skill in `~/.claude/skills`, no `## Citations` rule in `~/.claude/CLAUDE.md`.
- **Date:** 2026-10-30
- **Model:** `claude-opus-5-5` via `claude -p`, each run in a fresh empty directory outside the repo (`evals/run.sh`; see method note).
- **Runs:** 6 prompts × 3 runs. Citations extracted by a grader subagent (`baseline-extraction.json`), checked by `grade.py`.

marked-unverified: 23, no-link: 26, ok: 23, ok-preprint: 5, unchecked: 12, wrong: 1 (90 citations; 29 checked against a record)

## Summary

- 49 of 90 citations carry no link: 26 unflagged (prompt 4: 13, prompts 2 and 6: 5 each, prompt 1: 3), 23 flagged "from memory / unverified" (all 17 unlinked entries in prompt 3, 5 in prompt 2, 1 in prompt 5).
- Of the 29 citations whose link `grade.py` can check (DOI or arXiv ID), 1 is wrong. `ok-preprint` rows are checked on authors, title and earliest year only, because a bare arXiv record carries no journal venue. The wrong one: run 3-2 gives Zadravec et al. (2010) the DOI 10.1111/j.1467-8659.2010.01764.x, which resolves to Ovsjanikov et al., "One Point Isometric Matching with the Heat Kernel" — a wrong-DOI error of the kind Chelli et al. measured ([JMIR 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11153973/)). It is not flagged as unverified. 12 more links point to pages (publisher, repository, PDF, GitHub) that `grade.py` does not check.
- No same-author merge: all three prompt-6 runs reject the 2024 *Automation in Construction* paper and point to the two real 2023 papers, and prompt 1 keeps the CAD paper and JAX FDM apart.

## Method note

- A first attempt dispatched the runs as subagents of the implementing session. Their working directory was this repo, and 4 of 6 found and used `scripts/cite.py` unprompted, so that run was discarded. All 18 runs here were re-done with `claude -p` from empty directories (`evals/run.sh`).
- For prompt 5 the code went to `fdm.py` in the run directory; it is appended to each `5-<n>.md` so the docstring is graded (`run.sh` now does this automatically).
- The environment is the user's normal one: some answers mention other installed lookup tools (e.g. a librarian database). The gate arm runs in the same environment, so this is shared by both arms.
- arXiv links are checked against the preprint record, which cannot refute a later journal venue or publication year; `grade.py` then checks authors, title and that the year is not before the preprint, and reports `ok-preprint`.
