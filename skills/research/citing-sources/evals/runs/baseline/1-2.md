Rafael Pastrana (Princeton, working with Sigrid Adriaenssens and Ryan P. Adams) has four main publications on form-finding with automatic differentiation:

1. **"Constrained Form-Finding of Tension–Compression Structures using Automatic Differentiation"**, *Computer-Aided Design* vol. 155 (2023), arXiv:2111.02607, with four coauthors.
   - It uses reverse-mode automatic differentiation to get exact gradients of the Combinatorial Equilibrium Modeling (CEM) form-finding method. Those gradients drive optimization that meets force and geometry constraints.
   - It adds a new element called the "auxiliary trail", which widens the range of structures CEM can form-find.
   - Test cases are a self-stressed planar tensegrity, a tree canopy, a curved suspension bridge and a spiral staircase. An open-source Python design tool comes with it.

2. **"JAX FDM: A differentiable solver for inverse form-finding"**, ICML 2023 workshop, arXiv:2307.12407, with Deniz Oktay, Ryan P. Adams and Sigrid Adriaenssens.
   - It builds the force density method (FDM) in JAX with differentiable sparse operations and gradient-based optimization, to solve inverse form-finding.
   - Because the solver is differentiable, it can be dropped into a neural network and trained end-to-end. The library is open source at [arpastrana/jax_fdm](https://github.com/arpastrana/jax_fdm).

3. **"Real-time design of architectural structures with differentiable mechanics and neural networks"**, ICLR 2025, arXiv:2409.02606, with Eder Medina, Isabel M. de Oliveira, Sigrid Adriaenssens and Ryan P. Adams.
   - It pairs a neural network with the differentiable FDM simulator so bar-system shapes can be designed in real time.
   - The authors report that it generalizes better than purely neural models and comes close to the accuracy of direct optimization. Examples are masonry shells and cable-net towers.
   - They also run it inside 3D modeling software and build a physical prototype. Code is at princetonlips/neural_fdm.

4. **"Differentiable force density method for the design of lightweight structures"**, *Computer Methods in Applied Mechanics and Engineering* vol. 458, article 118783 (2026). This is the journal version of the JAX FDM work, with Kai-Uwe Bletzinger added as an author. I only found it in the jax_fdm repository's citation list and didn't read it.
