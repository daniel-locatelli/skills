I wrote the solver in `fdm.py` (about 60 lines, NumPy only) and ran it; the results check out.

**Source cited in the docstring:** H.-J. Schek, "The force density method for form finding and computation of general networks," *Computer Methods in Applied Mechanics and Engineering* 3(1):115–134, 1974, doi:10.1016/0045-7825(74)90045-0. I wrote this citation from memory and didn't look it up, so check the volume, pages and DOI before using it in a paper.

**How it works:**
- Each cable gets a force density *q* (force divided by length). The script builds a table of which cable connects which nodes and splits it into free and anchored nodes.
- This makes equilibrium a linear system, `D xₙ = p − D_f x_f`, with `D = Cₙᵀ Q Cₙ` and `D_f = Cₙᵀ Q C_f`. It solves that once for x, y and z together.
- It returns the final node positions, the cable forces and the cable lengths.

**Checks:**
- **Hand-calculable case:** one free node hangs between two anchors 2 apart, with *q* = 1 and a load of −1. It settles at z = −0.5 and each cable carries a force of 1.118, which matches the hand calculation.
- **Demo in `__main__`:** a 5×5 grid held at its four corners, two of them raised, under a light downward load. It forms a smooth saddle that is symmetric as expected.

I changed the demo partway through. The first version anchored the whole edge of the grid, so the raised corners were attached only to other anchored nodes and didn't change the shape at all.

The solver uses a dense matrix, which is fine for small nets. For large nets you'd switch `D` to a sparse matrix (`scipy.sparse`) and solve it with `spsolve`.

## File written by the run: `fdm.py`

```python
"""Force density method (FDM) for form finding of cable nets.

Reference
---------
H.-J. Schek, "The force density method for form finding and computation of
general networks," Computer Methods in Applied Mechanics and Engineering,
vol. 3, no. 1, pp. 115-134, 1974. doi:10.1016/0045-7825(74)90045-0

Each branch i gets a force density q_i = s_i / l_i (axial force over length).
With the branch-node connectivity matrix C split into free (C_n) and fixed
(C_f) columns, equilibrium at the free nodes becomes linear:

    D   = C_n^T Q C_n
    D_f = C_n^T Q C_f
    D x_n = p - D_f x_f        (solved independently for x, y and z)

where Q = diag(q) and p holds the external nodal loads.
"""

import numpy as np


def fdm(vertices, edges, fixed, q, loads=None):
    """Solve the force density equilibrium of a cable net.

    Parameters
    ----------
    vertices : (n, 3) array_like  Initial coordinates; fixed rows are kept.
    edges    : (m, 2) array_like  Node index pairs for each branch.
    fixed    : sequence of int    Indices of anchored (support) nodes.
    q        : float or (m,)      Force density per branch.
    loads    : (n, 3) array_like  External nodal loads (default: zero).

    Returns
    -------
    xyz     : (n, 3) ndarray  Equilibrium coordinates.
    forces  : (m,) ndarray    Branch forces s = q * l.
    lengths : (m,) ndarray    Branch lengths l.
    """
    xyz = np.array(vertices, dtype=float)
    edges = np.asarray(edges, dtype=int)
    n, m = len(xyz), len(edges)
    q = np.broadcast_to(np.asarray(q, dtype=float), (m,))
    p = np.zeros((n, 3)) if loads is None else np.asarray(loads, dtype=float)

    fixed = np.asarray(fixed, dtype=int)
    free = np.setdiff1d(np.arange(n), fixed)

    C = np.zeros((m, n))
    C[np.arange(m), edges[:, 0]] = 1.0
    C[np.arange(m), edges[:, 1]] = -1.0
    Cn, Cf = C[:, free], C[:, fixed]

    CnTQ = Cn.T * q  # same as Cn.T @ diag(q)
    D = CnTQ @ Cn
    Df = CnTQ @ Cf
    xyz[free] = np.linalg.solve(D, p[free] - Df @ xyz[fixed])

    lengths = np.linalg.norm(C @ xyz, axis=1)
    return xyz, q * lengths, lengths


if __name__ == "__main__":
    # 5x5 grid net anchored at its four corners, two of them raised:
    # a four-point (hypar-like) saddle under a small downward nodal load.
    k = 5
    idx = np.arange(k * k).reshape(k, k)
    verts = np.array([[i, j, 0.0] for i in range(k) for j in range(k)])
    edges = [(idx[i, j], idx[i, j + 1]) for i in range(k) for j in range(k - 1)]
    edges += [(idx[i, j], idx[i + 1, j]) for i in range(k - 1) for j in range(k)]
    corners = [idx[0, 0], idx[0, -1], idx[-1, 0], idx[-1, -1]]
    verts[idx[0, 0], 2] = verts[idx[-1, -1], 2] = 2.0
    loads = np.zeros_like(verts)
    loads[:, 2] = -0.1

    xyz, forces, lengths = fdm(verts, edges, corners, q=1.0, loads=loads)
    print("z:\n", np.round(xyz[:, 2].reshape(k, k), 3))
    print("max force: %.3f  max length: %.3f" % (forces.max(), lengths.max()))

```
