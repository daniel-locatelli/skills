I wrote a force density method solver in `fdm.py` (about 50 lines of code, using NumPy and SciPy sparse) and ran its demo successfully.

**Source cited in the docstring:**
- Schek, H.-J. (1974). "The force density method for form finding and computation of general networks." *Computer Methods in Applied Mechanics and Engineering*, 3(1), 115–134. doi:10.1016/0045-7825(74)90045-0
- It also credits the paper that first introduced the method: Linkwitz & Schek (1971), *Ingenieur-Archiv* 40, 145–158.

I cited both from memory and didn't look them up online, so check the DOI and page numbers before you rely on them.

**How it works:**
- `fdm(vertices, edges, fixed, q, loads=None)` builds the branch-node matrix `C` (one row per cable, one column per node) and splits it into free columns `Cₙ` and fixed columns `C_f`.
- It then solves `Dₙ Xₙ = P − D_f X_f` for all three coordinates, where `Dₙ = CₙᵀQCₙ` and `D_f = CₙᵀQC_f`.
- It returns the equilibrium coordinates, the axial forces (`q · L`) and the edge lengths.
- `q` can be one value per edge or a single number used for every edge.

**Demo (`python fdm.py`):** a 5×5 grid with only its four corners anchored and two opposite corners raised to z = 2, with q = 1. It forms a symmetric saddle with a flat middle row at z = 1, and edge forces range from 0.43 to 1.47.

Only the anchors' starting coordinates matter. The free nodes' starting positions don't affect the result, since the method finds the equilibrium shape for the chosen force densities in a single linear solve.

## File written by the run: `fdm.py`

```python
"""Force density method (FDM) for form finding of cable nets.

Source:
    Schek, H.-J. (1974). "The force density method for form finding and
    computation of general networks." Computer Methods in Applied Mechanics
    and Engineering, 3(1), 115-134. doi:10.1016/0045-7825(74)90045-0

    (Method first introduced in Linkwitz, K. & Schek, H.-J. (1971).
    "Einige Bemerkungen zur Berechnung von vorgespannten Seilnetzkonstruktionen."
    Ingenieur-Archiv, 40, 145-158.)

Each edge j gets a force density q_j = s_j / L_j (force over length). With
the branch-node matrix C = [C_n | C_f] split into free and fixed columns, the
nodal equilibrium equations become linear:

    D_n X_n = P - D_f X_f,    D_n = C_n^T Q C_n,    D_f = C_n^T Q C_f

where Q = diag(q). Solve once for all three coordinates.
"""

import numpy as np
from scipy.sparse import coo_matrix, diags
from scipy.sparse.linalg import spsolve


def fdm(vertices, edges, fixed, q, loads=None):
    """Solve for equilibrium positions of a cable net.

    Args:
        vertices: (n, 3) initial coordinates; only fixed rows are used.
        edges: (m, 2) vertex index pairs.
        fixed: indices of anchored vertices.
        q: (m,) force densities, or a scalar applied to every edge.
        loads: (n, 3) external nodal loads on vertices (default zero).

    Returns:
        xyz: (n, 3) equilibrium coordinates.
        forces: (m,) axial edge forces (q * length).
        lengths: (m,) edge lengths.
    """
    xyz = np.array(vertices, dtype=float)
    edges = np.asarray(edges, dtype=int)
    n, m = len(xyz), len(edges)
    q = np.broadcast_to(np.asarray(q, dtype=float), (m,))
    loads = np.zeros((n, 3)) if loads is None else np.asarray(loads, dtype=float)

    fixed = np.asarray(fixed, dtype=int)
    free = np.setdiff1d(np.arange(n), fixed)

    # Branch-node matrix: +1 at start vertex, -1 at end vertex of each edge.
    rows = np.repeat(np.arange(m), 2)
    cols = edges.ravel()
    vals = np.tile([1.0, -1.0], m)
    C = coo_matrix((vals, (rows, cols)), shape=(m, n)).tocsc()
    Cn, Cf = C[:, free], C[:, fixed]
    Q = diags(q)

    Dn = (Cn.T @ Q @ Cn).tocsc()
    Df = Cn.T @ Q @ Cf
    rhs = loads[free] - Df @ xyz[fixed]
    xyz[free] = np.column_stack([spsolve(Dn, rhs[:, k]) for k in range(3)])

    lengths = np.linalg.norm(C @ xyz, axis=1)
    return xyz, q * lengths, lengths


if __name__ == "__main__":
    # 5x5 grid net, corners anchored with two lifted, uniform force density.
    N = 5
    verts = [[i, j, 0.0] for j in range(N) for i in range(N)]
    idx = lambda i, j: j * N + i
    edges = [(idx(i, j), idx(i + 1, j)) for j in range(N) for i in range(N - 1)]
    edges += [(idx(i, j), idx(i, j + 1)) for j in range(N - 1) for i in range(N)]
    corners = [idx(0, 0), idx(N - 1, 0), idx(0, N - 1), idx(N - 1, N - 1)]
    verts[corners[1]][2] = verts[corners[2]][2] = 2.0  # hypar-like saddle

    xyz, f, L = fdm(verts, edges, corners, q=1.0)
    print("node z-coordinates:\n", np.round(xyz[:, 2].reshape(N, N), 3))
    print(f"edge forces: min {f.min():.3f}, max {f.max():.3f}")

```
