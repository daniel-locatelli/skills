I wrote a force density method solver in `fdm.py` and ran it once; the demo net comes out symmetric with plausible values. I didn't check the numbers against an independent solution.

**Source cited in the docstring:** H.-J. Schek, "The force density method for form finding and computation of general networks," *Computer Methods in Applied Mechanics and Engineering* 3(1):115–134, 1974, doi:10.1016/0045-7825(74)90045-0. I wrote this from memory and didn't look it up, so check the details before you publish it.

**How it works:** you set a force density q (force divided by length) for each cable. That makes the balance of forces at each node a linear equation, so the solver gets the free-node coordinates from one sparse linear solve:

`D_n x_n = p − D_f x_f`, where `D_n = C_nᵀ Q C_n` and `D_f = C_nᵀ Q C_f`

Here C is the incidence matrix (which nodes each cable connects), split into free and fixed columns, Q is a diagonal matrix of the q values, and p is the external loads.

**What you call:** `fdm(xyz, edges, q, fixed, loads=None)` returns the equilibrium node coordinates, the force in each cable (q × length) and each cable's length.

**Demo run:** `python fdm.py` builds a 5×5 grid with the boundary pinned, q = 1 on every cable and a load of 1 pointing down at every node. The centre node settles at z = −1.125 and the largest cable force is about 1.33.

## File written by the run: `fdm.py`

```python
"""Force density method (FDM) solver for cable nets.

Source:
    H.-J. Schek, "The force density method for form finding and computation
    of general networks," Computer Methods in Applied Mechanics and
    Engineering, vol. 3, no. 1, pp. 115-134, 1974.
    doi:10.1016/0045-7825(74)90045-0

For each edge, the force density q = force / length is prescribed. Nodal
equilibrium then becomes linear in the free-node coordinates:

    D_n x_n = p - D_f x_f,    with  D_n = C_n^T Q C_n,  D_f = C_n^T Q C_f

where C = [C_n | C_f] is the branch-node incidence matrix split into free (n)
and fixed (f) columns, Q = diag(q), and p holds the external nodal loads.
"""

import numpy as np
import scipy.sparse as sp
from scipy.sparse.linalg import spsolve


def fdm(xyz, edges, q, fixed, loads=None):
    """Solve for the equilibrium shape of a cable net.

    Parameters
    ----------
    xyz : (N, 3) array of initial node coordinates (fixed nodes keep theirs).
    edges : (M, 2) int array of node index pairs.
    q : (M,) array of force densities (positive for tension).
    fixed : sequence of fixed (support) node indices.
    loads : (N, 3) array of external nodal loads, default zero.

    Returns
    -------
    xyz : (N, 3) equilibrium coordinates.
    forces : (M,) axial force in each edge.
    lengths : (M,) length of each edge.
    """
    xyz = np.array(xyz, dtype=float)
    edges = np.asarray(edges, dtype=int)
    q = np.asarray(q, dtype=float)
    n_nodes, n_edges = len(xyz), len(edges)
    loads = np.zeros_like(xyz) if loads is None else np.asarray(loads, dtype=float)

    fixed = np.asarray(fixed, dtype=int)
    free = np.setdiff1d(np.arange(n_nodes), fixed)

    rows = np.repeat(np.arange(n_edges), 2)
    vals = np.tile([1.0, -1.0], n_edges)
    C = sp.csr_matrix((vals, (rows, edges.ravel())), shape=(n_edges, n_nodes))
    Cn, Cf = C[:, free], C[:, fixed]
    Q = sp.diags(q)

    Dn = (Cn.T @ Q @ Cn).tocsc()
    Df = Cn.T @ Q @ Cf
    rhs = loads[free] - Df @ xyz[fixed]
    xyz[free] = np.column_stack([spsolve(Dn, rhs[:, i]) for i in range(3)])

    lengths = np.linalg.norm(C @ xyz, axis=1)
    return xyz, q * lengths, lengths


if __name__ == "__main__":
    # 5x5 grid net, boundary pinned, uniform downward load on interior nodes.
    k = 5
    xyz = np.array([[i, j, 0.0] for j in range(k) for i in range(k)])
    idx = lambda i, j: j * k + i
    edges = [(idx(i, j), idx(i + 1, j)) for j in range(k) for i in range(k - 1)]
    edges += [(idx(i, j), idx(i, j + 1)) for j in range(k - 1) for i in range(k)]
    fixed = [idx(i, j) for j in range(k) for i in range(k)
             if i in (0, k - 1) or j in (0, k - 1)]
    loads = np.zeros_like(xyz)
    loads[:, 2] = -1.0

    xyz, forces, lengths = fdm(xyz, edges, np.ones(len(edges)), fixed, loads)
    print("centre node:", xyz[idx(2, 2)])
    print("max force:", forces.max().round(4))

```
