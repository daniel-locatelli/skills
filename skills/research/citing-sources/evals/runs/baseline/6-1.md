## Summary of the 2023 JAX FDM paper

- **Problem:** Inverse form-finding. The goal is shapes for 3D structures like domes, cable nets and towers that are structurally efficient and also hit set targets: a given shape, fabrication limits, or structural properties.
- **Method:** The force density method (FDM) is the forward solver, written in JAX so it can be differentiated automatically. Gradient-based optimization then works out the FDM inputs (mainly the force densities) that minimise a design objective. Differentiable sparse linear solves keep this efficient on large networks.
- **Integration:** Because the whole solver is differentiable, it can be combined with other libraries in the JAX ecosystem. That includes using it as a layer in a neural network trained end-to-end.
- **Examples:** (a) a shell that matches an arbitrary target shape, and (b) a cable net with prescribed edge lengths.
- **Code:** Open source at [arpastrana/jax_fdm](https://github.com/arpastrana/jax_fdm).
