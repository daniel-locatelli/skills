The classic reference is Kennedy & O'Hagan (2001, [JRSS-B 63](https://doi.org/10.1111/1467-9868.00294)):

> Kennedy, M. C. & O'Hagan, A. (2001). Bayesian Calibration of Computer Models. *Journal of the Royal Statistical Society Series B: Statistical Methodology* 63, 425-464. https://doi.org/10.1111/1467-9868.00294

It is usually called the "KOH framework." It sets up calibration with three parts:

- **A Gaussian-process emulator** that stands in for the computer model, which is too expensive to run many times.
- **A model-discrepancy term**, also a GP, which captures the systematic gap between the model and reality.
- **Observation error.**

The calibration parameters are inferred jointly with all three. Most later work on calibration with model discrepancy builds on this structure.

Kennedy published related papers around the same time, so make sure you cite the right one. The calibration paper is the JRSS-B one above. Two others are easy to confuse with it:

- **Multi-fidelity emulation**, with fast approximations of the code: Kennedy, M. C. (2000). Predicting the output from a complex computer code when fast approximations are available. *Biometrika*. https://doi.org/10.1093/biomet/87.1.1
- **Bayesian analysis of code outputs in general**: Kennedy, M. C., O'Hagan, A. & Higgins, N. A. (2002). Bayesian Analysis of Computer Code Outputs. Springer. https://doi.org/10.1007/978-1-4471-0657-9_11
