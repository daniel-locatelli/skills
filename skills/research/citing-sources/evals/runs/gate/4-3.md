The classic reference is Kennedy & O'Hagan (2001):

Kennedy, M. C. & O'Hagan, A. (2001). Bayesian Calibration of Computer Models. *Journal of the Royal Statistical Society Series B: Statistical Methodology* 63, 425–464. https://doi.org/10.1111/1467-9868.00294

It sets up what's now called the "KOH" framework: field observations = simulator output at the true calibration parameters + a **model discrepancy** term + observation error. The simulator and the discrepancy each get a Gaussian process prior, and the method infers the calibration parameters while accounting for code uncertainty, parameter uncertainty and model inadequacy. The journal version includes the published discussion, which is worth reading too.

**Don't confuse it with:**
- [Kennedy (2000), *Biometrika*](https://doi.org/10.1093/biomet/87.1.1). This is about predicting the output of an expensive code when fast approximations are available (multi-fidelity emulation). It is not the calibration paper.
- [Kennedy, O'Hagan & Higgins (2002)](https://doi.org/10.1007/978-1-4471-0657-9_11), "Bayesian Analysis of Computer Code Outputs." This is a Springer book chapter.
