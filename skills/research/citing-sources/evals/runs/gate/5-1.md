I wrote `fdm.py`, a linear force density solver for cable nets. I ran its demo and it works: a 5×5 grid with its four corners pinned, two of them raised, settles into a saddle shape under a uniform downward load, with a largest cable force of about 1.6.

**How it works:** `fdm(vertices, edges, fixed, q, loads)` builds the matrix that links each cable to its two end nodes. It then solves one sparse linear system, (C_fᵀ Q C_f) x_f = p_f − C_fᵀ Q C_x x_x, for the x, y and z coordinates. It returns the equilibrium node positions and each cable's force (q × length).

**Source in the docstring:** I looked the reference up on Crossref rather than writing it from memory, and copied it as recorded:

> Schek, H. J. (1974). The force density method for form finding and computation of general networks. *Computer Methods in Applied Mechanics and Engineering* 3, 115-134. https://doi.org/10.1016/0045-7825(74)90045-0

Schek published another cable-net paper the same year, with Linkwitz and Gründig, in German ([doi:10.1007/bf00534000](https://doi.org/10.1007/bf00534000)). It covers equilibrium with extra constraints, which this solver doesn't do, so the 1974 *Computer Methods in Applied Mechanics and Engineering* paper is the right one to cite.

It needs `numpy` and `scipy`. Run `python fdm.py` to see the demo.

## File written by the run: `fdm.py`

```python
"""Linear force density method (FDM) for cable-net form finding.

Given a force density q = force / length for every cable, the equilibrium
of the free nodes becomes a linear system:

    (C_f^T Q C_f) x_f = p_f - C_f^T Q C_x x_x

with C the branch-node incidence matrix split into free (f) and fixed (x)
columns, Q = diag(q), p the nodal loads and x the coordinates. Each of the
three coordinate directions is solved with the same matrix.

Source:
    Schek, H. J. (1974). The force density method for form finding and
    computation of general networks. Computer Methods in Applied Mechanics
    and Engineering 3, 115-134.
    https://doi.org/10.1016/0045-7825(74)90045-0
"""

import numpy as np
from scipy.sparse import coo_matrix, diags
from scipy.sparse.linalg import spsolve


def fdm(vertices, edges, fixed, q, loads=None):
    """Solve the equilibrium shape of a cable net.

    Parameters
    ----------
    vertices : (n, 3) array_like
        Initial node coordinates; only the fixed ones are used.
    edges : (m, 2) array_like of int
        Node index pairs, one per cable.
    fixed : sequence of int
        Indices of the supported (anchor) nodes.
    q : float or (m,) array_like
        Force density per cable.
    loads : (n, 3) array_like, optional
        External nodal loads. Defaults to zero.

    Returns
    -------
    xyz : (n, 3) ndarray
        Equilibrium node coordinates.
    forces : (m,) ndarray
        Axial cable forces, q * length.
    """
    xyz = np.array(vertices, dtype=float)
    edges = np.asarray(edges, dtype=int)
    n, m = len(xyz), len(edges)
    q = np.broadcast_to(np.asarray(q, dtype=float), (m,))
    p = np.zeros((n, 3)) if loads is None else np.asarray(loads, dtype=float)

    fixed = np.asarray(fixed, dtype=int)
    free = np.setdiff1d(np.arange(n), fixed)

    rows = np.repeat(np.arange(m), 2)
    cols = edges.ravel()
    vals = np.tile([1.0, -1.0], m)
    C = coo_matrix((vals, (rows, cols)), shape=(m, n)).tocsc()
    Cf, Cx = C[:, free], C[:, fixed]
    Q = diags(q)

    D = (Cf.T @ Q @ Cf).tocsc()
    rhs = p[free] - Cf.T @ Q @ Cx @ xyz[fixed]
    xyz[free] = np.column_stack([spsolve(D, rhs[:, k]) for k in range(3)])

    lengths = np.linalg.norm(C @ xyz, axis=1)
    return xyz, q * lengths


if __name__ == "__main__":
    # 5 x 5 grid net, corners pinned, two raised, uniform downward load.
    k = 5
    ij = [(i, j) for i in range(k) for j in range(k)]
    idx = {v: a for a, v in enumerate(ij)}
    verts = [[i, j, 0.0] for i, j in ij]
    edges = [(idx[i, j], idx[i + 1, j]) for i in range(k - 1) for j in range(k)]
    edges += [(idx[i, j], idx[i, j + 1]) for i in range(k) for j in range(k - 1)]
    corners = [idx[0, 0], idx[k - 1, 0], idx[0, k - 1], idx[k - 1, k - 1]]
    verts[idx[0, 0]][2] = verts[idx[k - 1, k - 1]][2] = 2.0
    loads = np.zeros((len(verts), 3))
    loads[:, 2] = -0.1

    xyz, f = fdm(verts, edges, corners, q=1.0, loads=loads)
    print(np.round(xyz, 3))
    print("max force:", round(f.max(), 3))

```
