I wrote `fdm.py`, a force density solver for cable nets that uses only NumPy. I ran its built-in example and the support reactions balance the applied load.

**The citation in the docstring.** I looked it up in Crossref rather than writing it from memory. Every field is copied from that record:

> Schek, H. J. (1974). The force density method for form finding and computation of general networks. *Computer Methods in Applied Mechanics and Engineering* 3, 115-134. https://doi.org/10.1016/0045-7825(74)90045-0

The lookup also turned up a different 1974 paper Schek co-wrote, Linkwitz, Schek & Gründig, *Die Gleichgewichtsberechnung von Seilnetzen unter Zusatzbedingungen* (https://doi.org/10.1007/bf00534000). It's about solving cable nets with extra constraints, so it isn't the original method paper. The docstring cites the CMAME paper by its DOI so the two can't be confused.

**What it does.** `fdm(vertices, edges, fixed, q, loads)` takes the net, the support nodes, a force density per edge (force divided by length) and optional loads. It solves the linear equilibrium system `(Cnᵀ Q Cn) xn = p − (Cnᵀ Q Cf) xf` for the positions of the free nodes. It returns:
- the equilibrium coordinates
- the axial force in each edge (`q × length`)
- the support reactions

Loads placed on support nodes are ignored.

**Test run.** The example is a 5×5 grid with the boundary pinned, `q = 10` on every edge, and a load of −1 in z on each node:
- The centre node settles at z = −0.1125.
- The largest edge force is 10.04.
- The vertical reactions add up to 9.0, which matches the 9 loaded interior nodes.

My first version got the reactions wrong: it counted the loads on the 16 support nodes, so the total came out as 25. I fixed that, and the run above is from the corrected version.

**Limits.** It builds the matrices as dense arrays, so it suits small and medium nets. For large nets, switch to `scipy.sparse` and `spsolve`.

## File written by the run: `fdm.py`

```python
"""Force density method (FDM) for cable nets.

Given each edge's force density q = force / length, the nodal equilibrium
equations become linear in the free-node coordinates:

    (Cn^T Q Cn) xn = p - (Cn^T Q Cf) xf

where C = [Cn | Cf] is the branch-node incidence matrix split into free and
fixed columns, Q = diag(q), p the loads on free nodes, and xf the fixed
(support) coordinates. One linear solve per coordinate gives the
equilibrium shape.

Source:
    Schek, H. J. (1974). The force density method for form finding and
    computation of general networks. Computer Methods in Applied Mechanics
    and Engineering 3, 115-134.
    https://doi.org/10.1016/0045-7825(74)90045-0
"""

import numpy as np


def fdm(vertices, edges, fixed, q, loads=None):
    """Solve for the equilibrium shape of a cable net.

    Parameters
    ----------
    vertices : (n, 3) array
        Initial coordinates. Only the rows in ``fixed`` are used.
    edges : sequence of (i, j)
        Node pairs, one per cable segment.
    fixed : sequence of int
        Indices of the support nodes.
    q : float or (m,) array
        Force density per edge.
    loads : (n, 3) array, optional
        External nodal loads. Loads on fixed nodes are ignored.

    Returns
    -------
    xyz : (n, 3) array
        Equilibrium coordinates.
    forces : (m,) array
        Axial force per edge (q * length).
    reactions : (n, 3) array
        Support reactions (zero on free nodes).
    """
    xyz = np.array(vertices, dtype=float)
    n, m = len(xyz), len(edges)
    q = np.broadcast_to(np.asarray(q, dtype=float), (m,))
    p = np.zeros((n, 3)) if loads is None else np.asarray(loads, dtype=float)

    fixed = np.asarray(fixed, dtype=int)
    free = np.setdiff1d(np.arange(n), fixed)

    C = np.zeros((m, n))
    for k, (i, j) in enumerate(edges):
        C[k, i], C[k, j] = 1.0, -1.0
    Cn, Cf = C[:, free], C[:, fixed]

    D = Cn.T @ (q[:, None] * Cn)
    Df = Cn.T @ (q[:, None] * Cf)
    xyz[free] = np.linalg.solve(D, p[free] - Df @ xyz[fixed])

    uvw = C @ xyz
    lengths = np.linalg.norm(uvw, axis=1)
    forces = q * lengths
    reactions = np.zeros((n, 3))
    reactions[fixed] = Cf.T @ (q[:, None] * uvw)
    return xyz, forces, reactions


if __name__ == "__main__":
    # 5x5 grid net, boundary pinned, unit downward load on interior nodes.
    N = 5
    vertices = [[i, j, 0.0] for j in range(N) for i in range(N)]
    idx = lambda i, j: j * N + i
    edges = [(idx(i, j), idx(i + 1, j)) for j in range(N) for i in range(N - 1)]
    edges += [(idx(i, j), idx(i, j + 1)) for j in range(N - 1) for i in range(N)]
    fixed = [idx(i, j) for j in range(N) for i in range(N)
             if i in (0, N - 1) or j in (0, N - 1)]
    loads = np.zeros((N * N, 3))
    loads[:, 2] = -1.0

    xyz, forces, reactions = fdm(vertices, edges, fixed, q=10.0, loads=loads)

    free = np.setdiff1d(np.arange(N * N), fixed)
    print("centre z:", xyz[idx(2, 2), 2].round(4))
    print("max force:", forces.max().round(4))
    print("sum Rz:", reactions[:, 2].sum().round(4),
          "(applied:", -loads[free, 2].sum(), ")")

```
