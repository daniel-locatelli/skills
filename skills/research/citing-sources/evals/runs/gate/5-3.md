I wrote the solver in `fdm.py`. Its docstring cites the paper that introduced the method:

> Schek, H. J. (1974). The force density method for form finding and computation of general networks. *Computer Methods in Applied Mechanics and Engineering* 3, 115-134. https://doi.org/10.1016/0045-7825(74)90045-0

I took the citation details from the Crossref record for that DOI rather than writing them from memory. Linkwitz, Schek & Gründig published a related 1974 paper in *Ingenieur-Archiv* on cable nets with extra constraints ([doi](https://doi.org/10.1007/bf00534000)). That one is a different paper; the method itself comes from the CMAME paper above.

**What it does:** you give each cable a force density q (axial force divided by length). With q fixed, the equilibrium equations become linear, so one sparse linear solve per axis gives the net's shape. The function `fdm(xyz, edges, q, fixed, loads)` returns the equilibrium coordinates and the axial force in each cable.

**Example run:** I ran the built-in example: a 5×5 grid with its four corners pinned at alternating heights (a saddle shape) and a uniform downward load of 0.1 per node. It runs without errors. The centre node settles at z ≈ 0.59, below the corners' mean height of 1.0, so the net sags under the load as expected. The largest cable force is about 1.60.

The script needs `numpy` and `scipy`.

## File written by the run: `fdm.py`

```python
"""Force density method (FDM) for cable nets.

Fixing a force density q = force / length on every edge makes the
equilibrium equations linear in the node coordinates, so one linear solve
per axis gives the form:

    D  = Cn^T Q Cn
    Df = Cn^T Q Cf
    D xn = p - Df xf          (same for y and z)

where C is the edge-node incidence matrix, split into free (Cn) and fixed
(Cf) columns, Q = diag(q), and p holds the external loads on free nodes.

Reference:
    Schek, H. J. (1974). The force density method for form finding and
    computation of general networks. Computer Methods in Applied Mechanics
    and Engineering 3, 115-134. https://doi.org/10.1016/0045-7825(74)90045-0
"""

import numpy as np
from scipy.sparse import coo_matrix, diags
from scipy.sparse.linalg import spsolve


def fdm(xyz, edges, q, fixed, loads=None):
    """Find the equilibrium shape of a cable net.

    Args:
        xyz: (n, 3) node coordinates; only fixed rows are used.
        edges: (m, 2) node index pairs.
        q: (m,) force densities, or a scalar for all edges.
        fixed: indices of supported nodes.
        loads: (n, 3) nodal loads; zero if omitted.

    Returns:
        xyz: (n, 3) equilibrium coordinates.
        forces: (m,) axial edge forces (q * length).
    """
    xyz = np.asarray(xyz, dtype=float)
    edges = np.asarray(edges)
    n, m = len(xyz), len(edges)
    q = np.broadcast_to(np.asarray(q, dtype=float), (m,))
    loads = np.zeros((n, 3)) if loads is None else np.asarray(loads, dtype=float)

    fixed = np.asarray(fixed)
    free = np.setdiff1d(np.arange(n), fixed)

    rows = np.repeat(np.arange(m), 2)
    cols = edges.ravel()
    vals = np.tile([1.0, -1.0], m)
    C = coo_matrix((vals, (rows, cols)), shape=(m, n)).tocsc()
    Cn, Cf = C[:, free], C[:, fixed]
    Q = diags(q)

    D = (Cn.T @ Q @ Cn).tocsc()
    Df = Cn.T @ Q @ Cf

    out = xyz.copy()
    out[free] = spsolve(D, loads[free] - Df @ xyz[fixed]).reshape(-1, 3)

    lengths = np.linalg.norm(C @ out, axis=1)
    return out, q * lengths


if __name__ == "__main__":
    # 5x5 grid net, corners pinned at alternating heights (hypar), self-weight.
    k = 5
    xyz = np.array([[i, j, 0.0] for j in range(k) for i in range(k)])
    idx = lambda i, j: j * k + i
    edges = [(idx(i, j), idx(i + 1, j)) for j in range(k) for i in range(k - 1)]
    edges += [(idx(i, j), idx(i, j + 1)) for j in range(k - 1) for i in range(k)]

    corners = [idx(0, 0), idx(k - 1, 0), idx(k - 1, k - 1), idx(0, k - 1)]
    for c, z in zip(corners, [0.0, 2.0, 0.0, 2.0]):
        xyz[c, 2] = z

    loads = np.zeros_like(xyz)
    loads[:, 2] = -0.1

    xyz, forces = fdm(xyz, edges, q=1.0, fixed=corners, loads=loads)
    print("centre node:", xyz[idx(2, 2)].round(4))
    print("max force:", forces.max().round(4))

```
